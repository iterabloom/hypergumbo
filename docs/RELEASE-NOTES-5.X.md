# Release notes — hypergumbo 5.x

The 5.x line comprises [5.0.0 and 5.0.1](../CHANGELOG.md#500---2026-05-09)
(see those CHANGELOG sections, which open with user-facing summaries).
Headlines: the Rust SCIP backend became usable end-to-end via
`pipx install 'hypergumbo[rust-analyzer]'`, and the extras-management
subcommands collapsed into the `add-extras` / `remove-extras` pair.

For the current major version line, see
[RELEASE-NOTES-6.X.md](RELEASE-NOTES-6.X.md).
