# hypergumbo-lang-mainstream

Popular language analyzers for hypergumbo.

## Supported Languages

See [docs/LANGUAGES.md](https://github.com/iterabloom/hypergumbo/blob/dev/docs/LANGUAGES.md) for the full list.

## Installation

```bash
# With core
pip install hypergumbo-core hypergumbo-lang-mainstream

# Full installation (recommended)
pip install hypergumbo
```

## Usage

```python
from hypergumbo_lang_mainstream.py import analyze_python
from hypergumbo_lang_mainstream.java import analyze_java
from hypergumbo_lang_mainstream.js_ts import analyze_javascript
```
